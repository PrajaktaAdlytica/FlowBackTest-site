Use and provenance

All logos contain filled vector paths, with no embedded images or font dependency. Created by vectorizing the selected generated board; original contours are preserved with spline smoothing. This set does not include a custom font.

Keep half a capital letter’s height of clear space around the wordmark. Prefer 180px or more in navigation; use FB where the full name cannot fit. White and reversed assets are transparent for dark surfaces. CurrentColor variants inherit color only when inlined.
