## QA acceptance checklist

- Check every public route, direct load, reload, fallback, internal link, anchor, footer link and CTA.
- Check field labels, invalid email, empty required fields, missing consent, local success, reset and no outbound form request.
- Check keyboard order, visible focus, skip links, menu open/close/Escape and dialog focus handling.
- Check narrow/short screens, zoom, overflow, readable charts, intentional crop and stable image dimensions.
- Check both scroll directions, scene exit, route cleanup and no hidden critical copy.
- Check reduced motion: full text, complete diagrams, no forced smooth scroll or repeated transforms.
- Check solid-text contrast, alt text, decorative image handling and accessible names.
- Check build/runtime warnings, initial useful content, asset sizes, image lazy loading, layout shift, and animation work when offscreen.
- Check demo namespace, consent, duplicate event prevention and no false conversion events.
- Check actual storage against privacy copy; delete/revoke clears the documented data.
- Check no secrets, fixtures, third-party trackers, production connectors, real sending, writes or billing.

Record observed results in a separate QA record. A checked box needs reproducible evidence, not an inference from source code.
