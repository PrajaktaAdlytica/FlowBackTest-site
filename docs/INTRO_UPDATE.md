# Persistent garden video introduction

The homepage begins with a 100dvh introduction using the user's eight-second garden-gate video (Downloads/Camera_moving_through_garden_gates_20261013001023.mp4). Video is muted and plays inline once. After completion, it scrolls into the existing hero only while the visitor is still at the top and motion is enabled. Manual scrolling is never locked; the intro remains in the document when scrolling back. Playback can be paused and replayed.

Adapted the supplied Riverine composition to FlowBackTest branding, existing self-hosted fonts and original navigation. The existing React site and all pages remain intact. Added three layered dark shades, cream CTA with dark arrow disc, clipped staggered headline entrances, font/video readiness and a 3.5-second visibility failsafe. The video has no audio toggle because playback is muted. Reduced-motion disables automatic playback, animated entrance and automatic hero transition.
