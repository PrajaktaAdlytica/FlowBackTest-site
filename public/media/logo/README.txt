FlowBackTest — Selected logo SVG set
Option 4: The Returning Wordmark

16 self-contained SVGs: five wordmark colors, five FB mark colors, two currentColor files, two app icons and two favicons.
All paths; no raster images, text nodes or external font dependency.
White/reverse SVGs are transparent and intended for dark backgrounds.
currentColor works when SVG is inlined; external img elements do not inherit page color.

Source and precision
Vectorized from the selected generated concept board, with spline smoothing and speckle removal. Lettering retains the selected board’s B return cut. This is an outlined logo, not a font. The small mark follows the FB study from that same board.

Usage
Prefer full wordmark at 180px+ wide; compact FB at 24px+. Favicon has square background and fuller glyph area. Browser rendering at 16px is a downsample, not a separate optically redrawn 16px mark.
Clear space: half a capital height for wordmark; quarter mark height for monogram.
Never stretch, add effects, alter letter spacing or fill with images.
Brand/domain clearance remains separate; selection is visual approval.
